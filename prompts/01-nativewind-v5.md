# 01 · NativeWind v5 setup

Status: done

## Goal
Configure NativeWind v5 (Tailwind CSS v4 + `react-native-css`) in the Expo SDK 58 app so components across native and web can be styled with `className` utilities and verified via a styled starter screen.

## Decisions
- **Package versions:** Use the latest npm `rc` tags (`nativewind@5.0.0-rc.1` pinned exact with `react-native-css@3.1.0-rc.1`, which includes Windows Babel path normalization fix `#390`), plus latest Tailwind v4 (`tailwindcss@^4`, `@tailwindcss/postcss@^4`, `postcss@^8`). Note: `https://www.nativewind.dev/llms-full.txt` documents v4 and links to the v5 guide at `https://www.nativewind.dev/v5/getting-started/installation`.
- **Root CSS location:** Place `global.css` at the project root (`./global.css`) and import it once in `src/app/_layout.tsx` (`import "../../global.css";`).
- **LightningCSS handling:** Keep `@expo/metro-config@58.0.23`'s resolved `lightningcss` (`1.33.0`) unless Metro bundling hits a `global.css` deserialization error; only if that error occurs, pin `lightningcss` via `package.json` `overrides`.
- **Existing Expo config:** Preserve `app.json` (`userInterfaceStyle: "automatic"`, `web.output: "server"`, `experiments.reactCompiler: true`) and existing SDK 58 native dependencies (`react-native-reanimated`, `react-native-worklets`, `react-native-safe-area-context`, `expo-system-ui` are already installed).
- **Babel setup:** Do not add `nativewind/babel` or `jsxImportSource: "nativewind"` (those are v4-only); NativeWind v5 uses `withNativewind` in `metro.config.js` with `babel-preset-expo`.
- **Verification screen:** Replace `StyleSheet.create` in `src/app/index.tsx` with NativeWind `className` utilities to verify styling end-to-end.

## Out of scope
- Installing `prettier-plugin-tailwindcss` or adding Tailwind settings to `.vscode/settings.json`.
- Defining Roam's full design-system color/typography/spacing tokens (to be added in a dedicated design-system feature).
- Modifying `ios/` or `android/` native directories.

## Steps

### 1. Install NativeWind v5 and Tailwind CSS v4 dependencies
Install the exact NativeWind v5 RC pair and Tailwind v4 PostCSS tooling in `package.json`:
- Runtime dependencies (pinned exact per NativeWind v5 requirement):
  `npm install --save-exact nativewind@5.0.0-rc.1 react-native-css@3.1.0-rc.1`
- Dev dependencies:
  `npm install --save-dev tailwindcss @tailwindcss/postcss postcss`
- Confirm existing Expo 58 native peers (`react-native-reanimated`, `react-native-worklets`, `react-native-safe-area-context`, `expo-system-ui`) pass `npx expo install --check`.

Done when `package.json` and `package-lock.json` include the packages cleanly with no peer conflicts.

### 2. Add PostCSS, Tailwind CSS, Metro, and TypeScript configuration
Create the four root configuration files required by NativeWind v5:
- `postcss.config.mjs` (must be `.mjs` or `.js`, not `.cjs`):
  ```js
  export default {
    plugins: {
      "@tailwindcss/postcss": {},
    },
  };
  ```
- `global.css` (split imports with unlayered utilities so React Native Web defaults do not override utility classes):
  ```css
  @import "tailwindcss/theme.css" layer(theme);
  @import "tailwindcss/preflight.css" layer(base);
  @import "tailwindcss/utilities.css";

  @import "nativewind/theme";
  ```
- `metro.config.js` (wrapping `expo/metro-config` with `withNativewind`):
  ```js
  const { getDefaultConfig } = require("expo/metro-config");
  const { withNativewind } = require("nativewind/metro");

  /** @type {import('expo/metro-config').MetroConfig} */
  const config = getDefaultConfig(__dirname);

  module.exports = withNativewind(config);
  ```
- `nativewind-env.d.ts` (included by `tsconfig.json` via `"**/*.ts"`):
  ```ts
  /// <reference types="react-native-css/types" />

  // NOTE: This file should not be edited and should be committed with your source code. It is generated by react-native-css. If you need to move or disable this file, please see the documentation.
  ```
  If TypeScript reports an unresolved CSS module import on `import "../../global.css"`, add `declare module "*.css";` in a separate declaration file (do not edit `nativewind-env.d.ts`, which is managed by `react-native-css`).

Done when all four root files exist and `npx tsc --noEmit` passes.

### 3. Import `global.css` and convert `src/app/index.tsx` to NativeWind
- Update `src/app/_layout.tsx` to import `"../../global.css"` at the top of the file.
- Update `src/app/index.tsx` to remove `StyleSheet.create` and style the welcome view and text with NativeWind `className` utilities (including `dark:` support, e.g. `flex-1 items-center justify-center bg-white dark:bg-black` and `text-xl font-bold text-blue-600 dark:text-blue-400`).

Done when `src/app/_layout.tsx` imports `global.css` and `src/app/index.tsx` renders with `className` props and passes TypeScript checking.
